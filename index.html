Notes

Handy formulas and reference snippets. These pair with the Excel Function tool — they use INDIRECT so they read from other open workbooks by file name.

Concatenate the same sheet from several open workbooks

Stack the table from a shared sheet (here Data) across a fixed list of open workbooks. Put each workbook's file name — exactly as shown in Excel's title bar, e.g. Book1.xlsx — in A1:A3. The A2:E100 range is the table body (row 2 down, skipping the header). 

=VSTACK(
  INDIRECT("["&$A$1&"]Data!A2:E100"),
  INDIRECT("["&$A$2&"]Data!A2:E100"),
  INDIRECT("["&$A$3&"]Data!A2:E100")
)

Same, but over a dynamic list of file names — real rows only

Loop over however many file names are in A1:A10 (blank cells are skipped, so leave spares) and stack each sheet's rows. This version reads each sheet's last used row from column A with COUNTA, so it pulls only rows that actually have data — no giant fixed range, no blank padding. Assumes column A is a key with no gaps inside the data. Change Data, the column letter in A:A, and the E (last data column) to fit your table. 

=LET(
  files, $A$1:$A$10,
  DROP(REDUCE("", files, LAMBDA(acc, f,
    IF(f="", acc,
      LET(
        base, "["&f&"]Data!",
        last, COUNTA(INDIRECT(base&"A:A")),
        IF(last<2, acc, VSTACK(acc, INDIRECT(base&"A2:E"&last)))
      )))), 1)
)

Variant — fixed range, filter the blanks out. If column A can have internal blanks (so COUNTA would undercount), pull a generous range instead and drop rows whose first column is empty. Note INDIRECT returns 0 for referenced blank cells, so the filter tests the first column against both 0 and "" — that's why a plain COUNTA(row)>0 filter doesn't work here. Keep the range at a few thousand rows (A2:E3000). 

=LET(
  files, $A$1:$A$10,
  stacked, DROP(REDUCE("", files, LAMBDA(acc, f,
    IF(f="", acc, VSTACK(acc, INDIRECT("["&f&"]Data!A2:E3000"))))), 1),
  keys, CHOOSECOLS(stacked, 1),
  FILTER(stacked, (keys<>0)*(keys<>""))
)

Across a list of files and a list of sheet names

File names in A1:A10, sheet names in B1:B5. For every file it stacks every listed sheet, then stacks all files together and trims blank rows. Handy when each workbook has several sheets to combine. 

=LET(
  files,  $A$1:$A$10,
  sheets, $B$1:$B$5,
  block, LAMBDA(f, DROP(REDUCE("", sheets, LAMBDA(b, s,
    IF(s="", b, VSTACK(b, INDIRECT("["&f&"]"&s&"!A2:E1000"))))), 1)),
  stacked, DROP(REDUCE("", files, LAMBDA(a, f,
    IF(f="", a, VSTACK(a, block(f))))), 1),
  FILTER(stacked, BYROW(stacked, LAMBDA(r, COUNTA(r)>0)))
)

Files × a list of possible sheets — skip missing, real rows only

File names in A1:A10, candidate sheet names in B1:B5. For every file it tries each sheet in the list, pulls the ones that exist, and silently skips any a file doesn't have — no #REF! errors. The pull helper wraps the existence check in IFERROR (a missing sheet makes INDIRECT return #REF!, which becomes a skip) and uses the last-row-from-column-A trick so only rows with data come through. Change A:A / A2:E to your key column and table width. 

=LET(
  files,  $A$1:$A$10,
  sheets, $B$1:$B$5,
  pull, LAMBDA(f, s,
    LET(
      base, "["&f&"]"&s&"!",
      last, IFERROR(COUNTA(INDIRECT(base&"A:A")), 0),
      IF(last<2, "", INDIRECT(base&"A2:E"&last))
    )),
  DROP(
    REDUCE("", files, LAMBDA(af, f,
      REDUCE(af, sheets, LAMBDA(a, s,
        LET(b, pull(f, s),
          IF(COLUMNS(b)=1, a, VSTACK(a, b))))))),
    1)
)

A sheet is treated as "present" when column A has at least a header plus one row; empty or header-only sheets are skipped too. The skip test COLUMNS(b)=1 works because every real block is pulled as A:E (multi-column), while a skip returns a single empty cell — so it holds regardless of how many rows match, as long as your table is more than one column wide.

Requirements & tips
  • Needs Excel 365 / 2024 (VSTACK, REDUCE, LAMBDA, LET, BYROW).
  • Every source workbook must be open — INDIRECT can't read closed files.
  • File names must match the title-bar name, including the extension (.xlsx, .xlsm).
  • All sheets should share the same column layout; start the range at row 2 to skip headers.
