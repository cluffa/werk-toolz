List Reconciliation

Paste two lists (one item per line) and see what's unique to each and what they share — the digital version of tying out two reports.

Excel Function Builder

Paste a normal formula and this rewrites every sheet-qualified reference (e.g. Sheet1!A1:A10) to point at another open workbook using INDIRECT, so the workbook file name can be supplied by string concatenation. Bare references like A2 are left untouched.

Lookup Builder

Build an XLOOKUP or VLOOKUP from its parts. Optionally point the search ranges at another open workbook via INDIRECT (same trick as the Excel Function tool).

Only sheet-qualified ranges (e.g. Sheet1!A:A) get redirected; the lookup value stays on the current sheet.
