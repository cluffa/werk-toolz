Python Wheelhouse

Playwright, pandas, numpy and the Excel readers as a single zip of wheels — installs on a machine with no internet access. Python 3.12.

Download for Windows

Download starts automatically. If it doesn't, use the button.

  • Windows (x86-64)
  • Linux (x86-64)
  • macOS (Apple silicon)

Install with uv

uv venv --python 3.12
uv pip install --no-index --find-links wheels -r requirements.txt

Install with pip

python -m venv .venv
.venv\Scripts\activate
python -m pip install --no-index --find-links wheels -r requirements.txt

What's inside

  • wheels/ — every wheel, dependencies included
  • requirements.txt — the pinned set
  • INSTALL.txt — the full instructions
  • install.ps1 / install.sh — one-shot installers
  • browsers/ — Playwright Chromium, ready for offline use

Packages

  • playwright — browser automation
  • pandas, numpy
  • openpyxl, python-calamine, xlrd, pyxlsb, XlsxWriter — Excel read/write
